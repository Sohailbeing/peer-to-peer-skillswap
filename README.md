Skillswap is a web-based peer-to-peer skill exchange
platform designed to promote collaborative learning through
intelligent matchmaking and real-time interaction. The system
enables users to create skill profiles, search for compatible
mentors or learners, schedule sessions, and communicate in
stantly through integrated messaging services. The platform is
implemented using a layered architecture comprising a React
and Next.js frontend, a Node.js for business logic processing
and MongoDB for scalable data storage.
